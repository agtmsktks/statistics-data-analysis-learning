# 07 AI 与大模型基础

在学习统计与数据分析的同时，理解 AI 工具本身的工作原理，做到"知其然也知其所以然"。

## 本章要点清单

- [ ] **智能体（Agent）**：大脑 + 工具 + 循环，ReAct 模式（`智能体-笔记.md`）
- [ ] **大模型的上下文（Context）**：窗口容量、滑动遗忘、注意力 O(N²)（`大模型上下文-笔记.md`）
- [ ] **智能体技能（Skill）**：三级渐进加载、描述触发、按需加载（`智能体技能-笔记.md`）

## 学习顺序建议

三个概念环环相扣，建议按序学习：

1. **智能体** —— 先认识"是什么在干活"
2. **上下文** —— 理解"它的工作台有多大、多贵"
3. **技能** —— 看"如何用按需加载突破窗口限制"

每个概念配有可运行的示例脚本（纯标准库）和三档练习，完成练习后勾掉上方清单。
