**第 1 题**：大脑 = 大模型（负责推理决策，如本例的 `think` 函数）；手脚 = 工具（可执行的操作，如本例的 `tool_add` 等三个函数）；循环 = 思考→行动→观察的反复执行（如 `run_agent` 的 while 循环）。

**第 2 题**：A = 对话（一问一答即结束）；B = Agent（有查看文件、写代码、运行、根据报错自我修正的多步循环）。

**第 3 题**：推演过程：`(10-4)*3+5` →第1步 sub(10,4)=6→ `6*3+5` →第2步 mul(6,3)=18 → `18+5` →第3步 add(18,5)=23 → `23`，最终答案 23，共 3 步。注意第 3 步是加法工具（op 为 `+`）。

**第 4 题**：错误在于"不会影响后面"。Agent 是**串行循环**，每一步的思考都基于上一步的观察结果，前一步算错（或工具返回错误），后面全部基于错误状态继续，误差会**累积放大**。这正是真实 Agent 系统需要结果校验和重试机制的原因。

**第 5 题**：参考实现：

```python
def tool_div(a, b):
    if b == 0:
        return 0  # 容错：除数为 0 视为 0，并打印警告
    return a // b
```

同时在 TOOLS 中注册 `"/": tool_div`，并让"行动"处打印警告。运行 `100/0+7`：第 1 步 div(100,0) 打印警告、返回 0，表达式变 `0+7`；第 2 步 add(0,7)=7，最终答案 7。注意正则 `[+\-*]` 需改为 `[+\-*/]`，且 `/` 在字符类中不用转义。
