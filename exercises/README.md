# 课后练习

## 练习 1（第 1 周）：换个数据集算一遍

用 `datasets/student_scores.csv` 的练习脚本作为模板，自己造一组数据（比如全班同学的身高），
重新计算所有统计量，并回答：

1. 均值和中位数哪个更大？说明分布是左偏还是右偏？
2. 有没有超出 1.5×IQR 边界的异常值？
3. 如果把最大的数换成原来的 10 倍，均值和中位数各怎么变？

## 练习 2（第 2 周预告）：标准差的直觉

一组数据 [10, 20, 30, 40, 50] 和 [28, 29, 30, 31, 32]，均值都是 30，
哪个标准差更大？先猜再用代码验证。
