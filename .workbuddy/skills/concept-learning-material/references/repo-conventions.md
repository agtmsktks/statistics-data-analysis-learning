## 命名规范

- 章节内资料文件：`{概念名}-笔记.md`、`{概念名}-示例.py`、`{概念名}-练习.md`（概念名用中文，不加空格）
- 示例数据：`datasets/{概念名}.csv`，UTF-8 编码，首行为表头
- 新章节目录：`NN-主题名/`（编号 = 现有最大编号 + 1），内含 README.md 说明本章要点清单

## 写作风格（对齐既有 week01-笔记.md）

- 简体中文，口语化但严谨；先直觉后公式，杜绝"先公式后解释"
- 公式：行内 `$...$`，独立公式 `$$...$$`
- 代码：优先 Python 标准库；脚本顶部写 docstring（含所属章节与运行方式）；打印输出带标签便于阅读
- 语气允许适度轻松（emoji 少量可用），但数值必须精确
- **数值一致性铁律**：笔记中的数字一律来自脚本真实运行输出；发现不一致时以脚本输出为准修正笔记
