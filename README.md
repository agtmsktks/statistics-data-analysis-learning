# 统计与数据分析学习仓库

📚 本仓库用于系统学习**统计与数据分析**课程，包含学习笔记、练习代码和数据集。

## 仓库结构

```
statistics-data-analysis-learning/
├── README.md               # 本文件：仓库说明
├── 学习计划.md              # 16 周学习路线图
├── 01-描述性统计/            # 均值、中位数、方差、分布形态
├── 02-概率论基础/            # 概率、随机变量、常见分布
├── 03-统计推断/              # 抽样、置信区间、假设检验
├── 04-回归分析/              # 线性回归、多元回归、模型评估
├── 05-数据可视化/            # 图表类型选择、可视化实践
├── 06-Python数据分析工具/    # NumPy / Pandas / Matplotlib
├── datasets/               # 练习用数据集
└── exercises/              # 课后练习
```

## 学习目标

1. 掌握统计学核心概念：描述统计、概率、推断统计
2. 能用 Python 完成完整的数据分析流程（数据清洗 → 探索分析 → 建模 → 可视化）
3. 培养用数据说话的思维方式

## 如何使用本仓库

```bash
# 1. 克隆到本地
git clone https://github.com/agtmsktks/statistics-data-analysis-learning.git

# 2. 学习后提交笔记和代码
git add .
git commit -m "学习笔记: 第X周"
git push origin main
```

> 💡 国内访问 GitHub 不稳定时，可尝试：多重试几次、切换手机热点、或使用加速工具。
